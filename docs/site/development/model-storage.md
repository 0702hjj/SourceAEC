# 模型存储

PostgreSQL 是业务持久化来源。磁盘目录是供转换器、Git 和沙箱使用的投影，
不要手工修改运行时 data 目录。通过 API 改变脚本、版本或项目状态。

Go 保存脚本、产品、元数据、暂存历史和 Git bundle。保存版本时，脚本、产品、
暂存清理及 Git 提交在同一事务中发布。执行失败保留当前状态；版本保存后不可变。
Go 编辑请求使用事务级模型锁，不依赖 Python 进程内缓存。

原生编辑、转换结果发布与模型状态更新在获取数据库连接前，共用按存储命名空间和
模型 ID 区分的进程内准入：每模型一个活动写入、最多 64 个等待者，取消后释放名额。
超出等待上限返回可重试错误，网关模型重试接口返回 429。
PostgreSQL 模型锁仍负责跨进程互斥；进程内准入不提供跨副本连接预算。
`modelWaiting` 统计共同准入的等待者，`editModelWaiting` 保留原生编辑等待统计。

脚本、参数与版本列表 GET 使用 PostgreSQL 只读快照，不等待同模型几何执行，也不从
未提交的磁盘暂存投影读取。运行、保存、回滚与分支操作先以短只读快照捕获
执行身份，释放连接后准备环境并执行。发布时获取模型锁，重新校验暂存、产品、
版本、Git 分支、项目归属与输入；任何变化返回 409，调用方读取新状态后重试。
每进程最多三个完整构建生命周期，等待发布的结果也计入预算；满载返回 429。
源码历史比较也在快照关闭后执行旧脚本，不持连接等待几何。
文件投影修改前记录路径 journal；进程重启时，以数据库已提交内容恢复被修改的
文件并删除未提交的新路径。恢复与正在发布投影的编辑事务互斥。

版本列表、保存编号与 Git 历史导入以数据库记录为准。首次编辑或列出旧模型版本时，
短写事务将旧 `versions` 产品文件迁入持久归档，再记录迁移完成标记；此后目录只是
投影，删除或添加临时目录文件不会改变版本。旧文件时间在可用时写入元数据；
无法恢复的旧时间保持空值。已有 journal 涉及的未提交路径会恢复并隔离，不作为历史版本导入。
升级时应停止旧写入进程，避免混用目录编号与数据库编号逻辑。

原生编辑使用类型化产物读写接口，共享私有 stdio 协议的事务与持久化规则，
大产品在进程内不再反复经过 JSON/base64 编解码。

构建输入通过单条数据库查询读取模型的项目归属及该项目的 plans/skill-work 输入，
复用调用者的事务与连接。文件投影缺失或落后不会改变传入沙箱的输入字节；
其他事务尚未提交的项目归属和输入也不会被采集。仅允许的 JSON/Python/DXF 输入
参与构建，历史目录排除，单文件上限 64 MiB、合计 256 MiB。
输入与源码属于同一 repeatable-read 快照，执行期间不持数据库连接或模型锁。
同一次请求只执行一次用户脚本；不同保存请求仍重新执行，不假定用户脚本具有确定性。

写事务同时提交短期凭据；COMMIT 应答丢失时，在模型锁下查询凭据以识别已提交状态。
无法连库确认时报告提交结果未知并保留 journal，不自动重新执行。凭据保留至少十分钟，
后续写事务清理过期记录；长时间断连后客户端应重新读取业务状态。
诊断接口 `sourceaecStages` 提供准备、环境、执行、发布及模型等待的累计次数和纳秒，
这些聚合值不代表请求分位数。

IFC 转换读取固定的已提交源和构建身份，完成时校验身份后发布。几何与 metadata
位于同一个不可变预览 generation；过期转换的成功或失败不能覆盖新源状态。
预览缓存丢失会重建；旧 generation 目前保留到模型删除，不自动回收。

转换入队等待模型准入时不持有队列互斥锁；发送前重新检查关闭状态与容量。
模型准入满时，仍可由有界转换队列接收任务，worker 重试发布已有结果，避免重复转换。

运行时模型源码可以具有 `.py` 后缀；这是数据库和临时工作区里的用户数据，
不是仓库维护的业务源码。外部依赖环境也不进入版本控制。

部署需要 `VIEWER_PG_DSN`，可用 `VIEWER_STORAGE_NAMESPACE` 隔离业务空间。
测试应使用独立数据库。升级前备份数据库和运行时目录。

升级包含投影恢复协议及产物摘要列的初始化，应先停止旧版本写入进程，再启动
新版本。首次初始化会计算已有产物的摘要；没有 generation 清单的旧预览会重新转换。

旧 SQLite 数据的离线迁移命令仍在 `server/cmd/migrate-sqlite`，需要 CGO，
不包含在默认静态二进制发行包中。

## 旧脚本兼容

迁移不修改既有运行时数据。旧脚本和产品可继续读取；若旧脚本导入了已退役的
本仓画法库，重新运行前需要将模型源码改为外部 SDK，或由管理员提供兼容的
外部运行环境。移除旧 SDK 不代表历史脚本自动获得新的库接口。
