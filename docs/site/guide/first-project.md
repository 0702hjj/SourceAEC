# 创建第一个项目

平台的用户入口是项目。Agent 在项目会话里操作模型，用户不需要手工上传文件。

## 操作流程

1. **新建项目**。在首页点「新建空白项目（AI 建模）」，填标题，选项目类型：
   - `ifc`：通过 Agent 创建和编辑 IFC。建项目时就初始化一个骨架模型。
   - `cad`：通过 Agent 创建和编辑 DXF，项目会话内按需初始化。
   - `cad->ifc`：先出图再转 IFC 的完整链路。
   - 类型创建后不可改，换管线要删项目重建。
2. **对话建模**。进入项目会话，在右侧 AI 对话栏用自然语言描述需求。系统按项目类型派发子 Agent 操作模型，过程中能看到工具调用卡片和中间预览。
3. **审查**。模型出现在项目模型列表里，点击进入查看器。IFC 走三维查看器，DXF 走二维画布。界面细节见[界面使用](/guide/interface)。
4. **编辑**。选中构件点定位脚本，跳到脚本对应行。改参数或改代码，沙箱验证后保存大版本。
5. **对比版本**。工具栏的 Diff 选择 base 和 target 做语义对比。

第 4、5 步的概念与操作见[编辑与版本](/guide/editing)。没有配置 LLM 时，chat agent 会退到离线模式：界面流程都能走通，但不会有真正的智能回复，配置方法见[配置说明](/guide/configuration)。
