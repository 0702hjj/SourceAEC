# 界面使用

前端只有两个页面：首页是项目与模型库，点进模型后是查看器页。IFC 模型挂三维查看器，DXF 模型挂二维画布。本文按使用顺序介绍各块界面；怎么改模型见[编辑工作流](/guide/editing)。

## 项目与模型库

首页分两块：项目和模型列表。

新建项目点「新建空白项目（AI 建模）」，填标题，选类型。类型有三种：`ifc` 让 Agent 操作 IFC 模型，`cad` 让 Agent 操作 DXF 图纸，`cad->ifc` 是先出图再转 IFC 的完整链路。一个项目对应一个会话。

历史项目列出所有会话，点进去可以继续对话。删除项目会连带清掉会话记录、方案文件和项目下的所有模型。

模型列表展示 agent 在项目里生成的每个模型，标明 IFC 还是 DXF、大小、状态和创建时间。状态从 `converting` 变成 `ready` 就能点开看；转换失败会显示 `failed`，可以重试。列表里还可以下载原始文件或删除模型，删除会连带清理转换产物和 Issue。

> 模型不再由用户直接上传，上传入口已隐藏，模型一律由 agent 在项目会话里生成。

## IFC 三维查看器

IFC 模型有两条渲染链路，在界面右上角切换，默认 xeokit：

- **xeokit**：加载预转换的 XKT 数据，工具链最全，模型树、剖切、测量、Issue 钉、Diff 着色都在这条链路上。
- **web-ifc**：浏览器里直接读 IFC 原件，不等转换。有渲染、旋转、空间树、属性和选中高亮，但没有高级工具。

### 模型树与属性

左侧模型树按空间结构组织，从 Site 到 Building 到 Storey 再到构件。支持按名称或 IFC 类型搜索过滤，每个节点可以单独隐藏。点击节点，相机会飞到该构件并高亮。

右侧属性面板显示选中构件的属性集，可折叠、搜索、复制。属性是只读的——要改值得走脚本，见[编辑工作流](/guide/editing)。

### 视图工具

- 可见性工具栏：隐藏选中、隔离、X-Ray 半透明、重置。
- 剖切：三个方向的滑杆，用来切开模型看内部。
- 测量：点两个构件量距离，双击结束。
- NavCube 提供方向指示和视图切换。

## DXF 二维画布

DXF 模型走 Canvas 二维画布，图层颜色和线型按 DXF 原语义渲染，坐标保持原图纸坐标系。选中带 key 的实体，面板会出现**定位脚本**按钮，点击跳到生成它的脚本行，和 IFC 侧的定位是同一条链路。

## Issue 与 3D 钉

审查中发现问题，操作是：

1. 选中构件，在底部 Issue 面板点「新建 Issue」，填写标题和评论。
2. 创建时自动带上当前视角和画布截图，3D 钉会投影到构件位置。
3. 点钉或列表条目，恢复创建时的视角并选中构件。
4. Issue 状态在 open、checking、resolved 之间流转。

底部的「修改历史」标签页按时间倒序展示每次修改：改了哪个实体、哪个字段、旧值新值各是什么。

## AI 对话侧栏

项目会话右侧是可折叠的 AI 对话栏。用自然语言描述需求，agent 就开始建模。消息流里有文本、推理过程和工具调用卡片，ifc-agent 和 cad-agent 的输出分组展示。agent 中途向你提问时，弹框回答即可继续。试运行成功后画布上能直接看到中间结果，详见[编辑工作流](/guide/editing)。
