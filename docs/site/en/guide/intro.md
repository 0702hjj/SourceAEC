# Introduction

SourceAEC is a self-hosted interface for IFC authoring, editing, inspection and versioning.
People and agents share script-as-source APIs. Go owns business validation, state, sandbox orchestration,
persistence, versions, optional planning delivery and MCP integration.

Model scripts use external IfcOpenShell, ezdxf or an administrator-provided geometry runtime.
Python is an execution dependency; this repository ships no maintained Python application or SDK.
The browser provides a project library, IFC properties and 3D views, DXF previews, review issues and chat.

Start with [requirements and startup](/en/operations/quickstart), then [your first project](/en/guide/first-project).
For system responsibilities, see [architecture](/en/architecture/overview).
