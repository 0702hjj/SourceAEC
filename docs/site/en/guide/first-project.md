# First project

1. Create a project from the library. Choose `ifc`, `cad` or `cad->ifc`. The kind is fixed at creation;
   changing pipelines requires a new project. IFC projects initialize a skeleton model; CAD models are initialized when needed.
2. Describe the model in the project chat. Tool cards show progress and intermediate previews.
3. Open the model to review IFC geometry/properties or the DXF canvas.
4. Select an entity to locate its source, change parameters or code, run the sandbox, then save an immutable version.
5. Compare base and target versions in the Diff panel.

Without a configured LLM, the deterministic offline model supports interface testing, not full natural-language modeling.
See [configuration](/en/operations/configuration), [editing](/en/guide/editing) and [external agents](/en/integrations/agents).
